# Design Principles

## 1. Optimise for immediate decision-making
The interface should help users make a fast choice in the moment, not perform deep research.

## 2. Prioritise recency over history on the main dashboard
The primary view should emphasise what is happening now. Historical analysis should be separate from the live dashboard experience.

## 3. Make comparison effortless
Users should be able to compare multiple stores at a glance without opening detail pages.

## 4. Show confidence alongside score
A score without context can mislead. Every visible performance signal should be paired with an indication of how much recent feedback supports it.

## 5. Avoid false precision
The product should present recent customer-rated sentiment clearly, without implying a level of scientific measurement that the data does not justify.

## 6. Design for mobile first
The dashboard should be easy to scan, sort, and interact with on a mobile device.

## 7. Reward contribution without distorting behaviour
Badges and profile mechanics should encourage participation, but should not incentivise spammy or low-quality ratings.

## 8. Be transparent about data freshness
Users should always be able to see how recently a store signal was updated and what time window is being used.
