# Dashboard Concept

## Dashboard layout
A store row should include:
1. Brand or store icon
2. Store name
3. Service gauge
4. Speed gauge
5. Freshness gauge
6. Order accuracy gauge
7. Confidence indicator
8. Last updated time

## UX principles
- make comparison fast
- prioritise scanability on mobile
- emphasise recency and confidence
- avoid over-precision in the visual language
- make it obvious when there is limited data

## Interaction notes
- default to nearby stores
- allow sorting by strongest current score, highest confidence, and most recent update
- allow changing the time window without leaving the dashboard
- expose supporting detail such as rating count in tooltip or expanded state
