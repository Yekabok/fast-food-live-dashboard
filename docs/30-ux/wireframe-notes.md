# Wireframe Notes

## 1. Dashboard screen
### Header area
- logo or product name
- area selector
- time-window selector
- sign-in or profile entry point

### Main content
A vertically scrollable list of store rows.

### Store row layout
- store icon
- store name
- service gauge
- speed gauge
- freshness gauge
- order accuracy gauge
- confidence label or badge
- last updated time

### Interaction options
- sort control
- filter control if needed later
- tap row for expanded detail if required

## 2. Rating submission flow
### Entry
- button from dashboard or store row for signed-in users

### Form
- selected store identity
- four rating inputs
- submit action

### Completion
- success confirmation
- optional badge or contribution acknowledgment

## 3. Profile screen
### Content blocks
- user identity
- contribution count
- earned badges
- recent rating activity

## 4. Trends screen
### Content blocks
- date-range selection
- store comparison selector
- trend graphs by metric
- summary insights

## UX notes
- Dashboard rows should be compact but still readable on mobile.
- Gauge labels may need abbreviation or icon support on smaller screens.
- Confidence and last updated time should remain visible without expanding the row.
- The layout should support both quick scan and optional deeper inspection.
