# MVP Scope and Roadmap

## MVP
- public dashboard
- area-based store discovery
- four core rating gauges
- confidence indicator
- last updated timestamp
- 15-minute default time window with configurable alternatives
- Google and Apple sign-in
- user profiles and badges
- structured rating submission

## Phase 2
- historical analytics
- trend reporting
- richer profile mechanics
- stronger anti-abuse tooling
- deeper confidence modelling

## Open questions
- exact store discovery method
- store source data strategy
- exact contribution limits and anti-abuse rules
- whether to allow comments at launch
- public visibility settings for user profiles
