# Project Charter

## Working title
Fast Food Live Dashboard

## Product vision
A public website that helps people see the recent customer-rated performance of fast food stores in their area, using near real-time crowd-sourced feedback.

## Core idea
Users can view a dashboard of nearby establishments and see recent ratings for service, speed, freshness, and order accuracy. Signed-in users can contribute ratings from their recent experience.

## Primary outcome
Help users decide which fast food location is performing best right now.

## Secondary outcome
Build a historical data set that can later support trend analytics over weekly, monthly, and longer time periods.
