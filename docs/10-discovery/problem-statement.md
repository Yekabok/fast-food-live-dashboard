# Problem Statement

People often choose fast food locations based on convenience or brand, but actual store performance can vary significantly by location and by time of day.

Today, consumers lack a simple way to understand how a specific nearby store is performing right now across operational factors such as service, speed, freshness, and order accuracy.

Existing review platforms tend to be historical, text-heavy, and not designed to reflect current conditions.

This project aims to provide a lightweight public dashboard of recent customer-rated performance so users can make better immediate decisions.
