# Fast Food Live Dashboard

Public website concept for near real-time, crowd-sourced visibility into current fast food store performance.

## Purpose
This repository holds the product, business, UX, legal, and technical documentation for the project.

## Initial structure
- `docs/00-overview/` - product summary and vision
- `docs/10-discovery/` - problem statement, assumptions, research notes
- `docs/20-requirements/` - functional and non-functional requirements
- `docs/30-ux/` - user journeys, wireframes, interface behaviour
- `docs/40-data/` - data model, scoring, confidence logic
- `docs/50-compliance/` - legal, privacy, and policy notes
- `docs/60-delivery/` - roadmap, MVP scope, decisions, risks

## Status
Scaffolding created. Initial specification documents in progress.
